# 🎮 Drag & Drop 

 **HTML, CSS, and JavaScript**, featuring a simple drag-and-drop interface for placing X and O pieces on the board.

## ✨ Features

* 🎯 Drag and drop X & O pieces
* 🔄 Restart button
* 🎨 Clean and simple UI
* ⚡ Built with vanilla HTML, CSS & JavaScript

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 📌 Project Purpose

This project was created to practice **HTML, CSS, JavaScript, DOM manipulation, and Drag & Drop events** while building a responsive web interface.
